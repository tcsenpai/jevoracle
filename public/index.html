Jev Oracle

typed questions over your state — not a chat

Jev answers in types, not sentences.

You send a state (whatever it should reason over) and a map of typed questions. It returns one typed answer per question, with calibrated probabilities — all in a single parallel call. The exact JSON is always visible on the right, and you can edit it directly.

Or load a worked example:

State

Everything Jev sees. Untick a source and resend to measure how much the answer depended on it. Several sources are sent as a named JSON object.

Questions

Every enabled question is answered in the same call, in parallel. They cannot see each other's answers. The one marked primary is rendered as the headline verdict.
